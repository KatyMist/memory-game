# Memory Game

Игра на поиск пар: открывайте карточки, запоминайте их расположение и находите все совпадения за наименьшее число ходов.

Задание курса RS School: [Memory Game](https://github.com/rolling-scopes-school/tasks/tree/master/tasks/memory-game)

**Деплой:** https://katymist.github.io/memory-game/

## Возможности

- 16 карточек (8 пар), которые перемешиваются при загрузке страницы и в каждой новой игре (алгоритм Фишера — Йейтса).
- Один ход — открытие двух карточек. Несовпавшая пара закрывается через 1 секунду, и пока она открыта, другие карточки выбрать нельзя.
- Счётчики ходов и найденных пар.
- Окно победы с итоговым числом ходов и кнопками «Новая игра» и «Закрыть».
- Таблица лидеров: 10 лучших результатов с сохранением в `localStorage`, сортировкой по числу ходов и датой в формате ДД.ММ.ГГГГ.
- Кнопка «Новая игра» перезапускает игру в любой момент без перезагрузки страницы.
- Модальные окна закрываются кнопкой, кликом по фону или клавишей Escape; прокрутка страницы на это время блокируется.
- Адаптивная вёрстка для компьютера и телефона.

## Технологии

- HTML, CSS, JavaScript (ES-модули), без библиотек и фреймворков.
- Вся разметка создаётся через `document.createElement` (обёртка `src/utils/create-element.js`), в `<body>` исходного `index.html` есть только `<script>`.
- Модальные окна — общий компонент на основе `<dialog>` (`src/components/modal.js`).

## Запуск локально

Приложение использует ES-модули, поэтому его нужно открывать через локальный сервер, а не двойным кликом по `index.html`.

1. Клонируйте репозиторий и перейдите в ветку `memory-game`:

   ```bash
   git clone https://github.com/KatyMist/memory-game.git
   cd memory-game
   git checkout memory-game
   ```

2. Запустите любой локальный сервер в папке проекта, например:

   - **VS Code:** расширение Live Server → правый клик по `index.html` → **Open with Live Server**;
   - **Node.js:** `npx serve .`
   - **Python:** `python3 -m http.server 8080`

3. Откройте в браузере адрес, который покажет сервер (например, http://localhost:8080).

## Структура проекта

```
├── index.html               # пустой <body> и подключение скрипта
├── styles/style.css         # стили
├── assets/                  # иллюстрации карточек, иконки, декор
└── src/
    ├── main.js              # точка входа: сборка приложения
    ├── game/game.js         # игровая логика и состояние партии
    ├── components/          # хедер, счётчики, поле, карточка, кнопка, модальное окно и его содержимое
    ├── storage/leaderboard.js  # работа с localStorage
    ├── data/cards.js        # набор карточек
    └── utils/               # createElement, перемешивание, колода, дата, склонение
```

## Изображения

Иллюстрации животных сгенерированы с помощью ИИ. Логотип, рубашка карточек, иконки и декоративные элементы нарисованы в SVG специально для проекта.
